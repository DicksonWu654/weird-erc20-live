# Independent V3 aggregates

`recall.csv` retains sample-conditional independent verdict confusion metrics with Wilson limits and explicit unknown/unsupported scope. It does not identify population recall or validate historical transport. `v3_dust_summary.csv` and `v3_default_floor_headline_sensitivity.csv` summarize quote-balance floor effects. Pool quote balance includes out-of-range and uncollected amounts; it is not active executable depth. Selected token lists, per-token measurements and raw evidence are omitted.
